# Ncloud SENS SMS 설정 가이드

Ncloud SENS로 문자 발송 기능을 붙이기 전에 콘솔에서 먼저 준비해야 할 항목입니다.

## 1. 계정 확인

SENS는 현재 사업자 계정으로만 이용 가능합니다.

개인 계정이면 문자 발송용 SENS 프로젝트를 만들 수 없으므로 먼저 사업자 계정인지 확인하세요.

## 2. SENS 프로젝트 생성

Ncloud 콘솔에서 아래 메뉴로 이동합니다.

```text
Menu > Services > Application Services > Simple & Easy Notification Service > Project
```

이후 **[프로젝트 생성하기]**를 눌러 프로젝트를 생성합니다.

- 프로젝트 이름 입력
- 프로젝트 설명 입력
- 서비스 유형에서 `SMS` 선택

프로젝트가 만들어지면 서비스 유형별로 Open API 호출에 필요한 `Service ID`가 자동 할당됩니다.

## 3. 발신번호 등록

아래 메뉴에서 프로젝트를 선택한 뒤 **[발신번호 등록]**을 누릅니다.

```text
SENS > SMS > Calling Number
```

신청 시 입력하거나 업로드해야 하는 정보는 다음과 같습니다.

- 이름: 법인명 또는 번호 소유주명
- 발신번호
- 필요 서류
- 요청 내용

업로드 파일 조건은 다음과 같습니다.

- 파일 형식: `PDF`, `JPG`, `PNG`
- 총 용량: 10MB 이내
- 승인 기간: 영업일 기준 3~4일 정도 소요될 수 있음

승인된 발신번호만 실제 문자 발송에 사용할 수 있습니다.

## 4. API 인증키 생성

파이썬 또는 백엔드 API에서 문자를 발송하려면 Ncloud API 인증키가 필요합니다.

Ncloud 콘솔 우측 상단에서 아래 메뉴로 이동합니다.

```text
My Account > 계정 및 보안 관리 > 보안 관리 > 접근 관리
```

이후 **[신규 인증키 생성]**을 눌러 인증키를 생성합니다.

필요한 값은 다음 2개입니다.

- `Access Key`
- `Secret Key`

서브계정을 사용하는 경우, 메인 계정이 먼저 API Gateway 접근 권한을 부여해야 인증키 메뉴가 보일 수 있습니다.

## 5. Service ID 확인

`Service ID`는 아래 위치에서 확인할 수 있습니다.

- `SMS > Message`
- `SMS` 화면의 서비스 정보 영역

이 값은 문자 발송 API 경로의 `{serviceId}` 자리에 들어갑니다.

```http
POST /sms/v2/services/{serviceId}/messages
```

## 6. 콘솔에서 테스트 발송

발신번호 승인이 끝나면 아래 메뉴에서 바로 테스트 발송을 할 수 있습니다.

```text
SENS > SMS > Message
```

**[메시지 발송]**을 눌러 테스트 문자를 보냅니다.

등록된 발신번호가 없으면 문자 발송이 되지 않으므로, 먼저 `Calling Number`에서 발신번호 등록과 승인을 완료해야 합니다.

발송 결과와 이력도 같은 메뉴에서 확인할 수 있습니다.

## 7. 광고 문자 발송 시 080 수신거부 준비

광고성 문자를 보낼 예정이면 아래 설정도 확인해야 합니다.

```text
SENS > SMS > 080 Block Call Service
```

SENS는 080 수신거부 서비스 신청과 관리 기능을 제공합니다.

## 최소 준비 체크리스트

- [ ] 사업자 계정 확인
- [ ] SENS 프로젝트 생성 및 서비스 유형 `SMS` 선택
- [ ] 발신번호 등록 및 승인
- [ ] `Access Key` / `Secret Key` 생성
- [ ] `Service ID` 확인

위 5개 항목이 끝나면 백엔드 또는 파이썬 코드에서 문자 발송 API를 연동할 수 있습니다.
